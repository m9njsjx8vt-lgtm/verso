# Verso — インストールガイド (奥さん向け)

Versoは選択したテキストを ⌘C×2 で瞬時に翻訳してくれる Mac アプリです。

## 1. インストール

1. 受け取った `Verso-vX.Y.Z.dmg` をダブルクリックして開く
2. 開いた画面で **Verso** を **Applications** フォルダにドラッグ
3. `Applications` の Verso をダブルクリック
4. ⚠️ **「不明な開発元」警告が出たら:**
   - 警告ダイアログは「キャンセル」で閉じる
   - `Applications` の Verso を **右クリック → 開く**
   - もう一度警告が出るので「**開く**」をクリック
   - これは**初回だけ**。以降は普通にダブルクリックで起動できます

## 2. 初回セットアップ

Verso が起動するとメニューバー（画面右上）に 🔤 のアイコンが出ます。

### Step 1: Gemini APIキーを取得（無料）

Versoは Google の Gemini AI で翻訳します。無料枠で十分使えます。

1. メニューバー🔤 → **Show Welcome Tour…** をクリック
2. 「Google AI Studio を開く」ボタン → ブラウザで開く
3. Googleアカウントでログイン → **Get API key** → **Create API key**
4. 表示された `AIza...` で始まる文字列を**コピー**
5. Verso のセットアップ画面の入力欄に**ペースト**
6. 「次へ」

### Step 2: DeepL APIキー（任意）

入れると翻訳が「即座に出る」体験になります。月50万文字まで無料。  
スキップしてもOK（後でいつでも追加できます）。

### Step 3: アクセシビリティ権限

⌘C×2 を検出するために必要です。

1. ガイドに従って「システム設定」を開く
2. **プライバシーとセキュリティ** → **アクセシビリティ**
3. リストに **Verso** が出ているのでトグル ON（Touch ID または パスワード）
4. メニューバー🔤 → **Quit Verso** で一度終了
5. もう一度 Applications の Verso をダブルクリックして再起動

## 3. 使い方

### 基本: ⌘C × 2

1. どこでもいいので翻訳したい文字を**選択**（クリック&ドラッグ）
2. ⌘C を **2回素早く**押す
3. ポップアップが出て翻訳が表示される
4. 「**↩ 挿入**」(Enter) → 元のアプリに戻って翻訳を貼り付け
5. 「**📋 コピー**」 → クリップボードにコピー
6. 「**閉じる**」(Esc) → 何もせず閉じる

### その他のショートカット

| キー | 動作 |
|---|---|
| ⌘⇧V | クリップボードに入っているテキストを翻訳 |
| ⌥⇧C | 画面の領域を選択 → OCR + 翻訳（PDFや画像内の文字も翻訳できる） |
| ⌘⇧H | 過去の翻訳履歴を検索 |
| メニューバー🔤 → Translate Frontmost Window | 今見ているウィンドウの全テキストを翻訳 |

### ポップアップ内のボタン

- **🔁 短く / 砕け / 丁寧 / 別案** — 翻訳のスタイルを変える
- **🔁 Pro** — より高品質モデルで再翻訳（時々無料枠を多く使うので頼りすぎ注意）
- **ふりがな** — 日本語訳に読み仮名を付ける（学習用）
- **🔊 スピーカーアイコン** — 翻訳を読み上げる
- **Edit** — 翻訳を直接編集 → 「Save & Learn」で Verso が修正パターンを覚える
- **用語追加** — 「DXPP」みたいな固有名詞をいつも同じ訳にしたい時

## 4. 翻訳のクセを教える（パーソナライゼーション）

Verso は以下を「あなた仕様」にできます:

### Settings → Personalization
あなたの好みのトーン、文体、業界の前提を文章で書く。例:
```
- 会社員として外資との会議録を翻訳することが多い
- 丁寧すぎる表現は避けて、簡潔・直接的に
- 専門用語はカタカナで残す
```

### Settings → Glossary
「この単語は必ずこう訳して」と登録できる。例:
- DXPP → Digital Transformation Performance Platform
- EARTHBRAIN → そのまま (Preserve as-is)

## 5. プライバシー

- 入力したテキストは **Google (Gemini) と DeepL** にのみ送信されます
- 翻訳履歴は **あなたのMacのみ**に保存されます (~/Library/Application Support/Verso/)
- API キーは**ローカルファイル**に owner-only 権限 (0600) で保管
- Verso 開発者（夫）にも何も送信されません

履歴を残したくない時は Settings → Behavior → **Privacy mode** ON。

## 6. 困ったとき

### ⌘C×2 押してもポップアップが出ない
1. メニューバー🔤 → **Check Accessibility Permission**
2. 「未許可」と出たらガイドに従って許可

### 翻訳が変
- Settings → Personalization にあなたの好み/文脈を追記
- Glossary に固有名詞を登録
- それでも変ならポップアップで Edit → Save & Learn
